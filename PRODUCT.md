# Personal profile

The owner's portfolio introduces their work to potential collaborators and employers. All personal details remain explicit placeholders until the owner supplies them.

Use Next.js App Router, React, TypeScript, Tailwind CSS, Framer Motion, GSAP ScrollTrigger, Lenis, next/font and next/image. Keep all editable copy in data/content.ts.

The site supports English and Thai. Circular UK and Thai flag controls select the language, with no visible language-name text. Each control has an accessible name, a keyboard focus indicator and a selected ring. Persist the selection in a first-party cookie and set the document language on the server. Keep the requested route names without locale prefixes.

Routes to build in later phases: /, /work, /work/[slug], /about, /contact and a custom 404.

All eight implementation phases are complete. Home, Work, case studies, About, Contact and the custom 404 support English and Thai. Phase 8 adds production performance checks and a guide for replacing content and publishing on Vercel. Personal content stays as placeholders.

No contact delivery service, analytics, external account changes or deployment is configured.
